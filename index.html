Open demo ↗ View code ↗

The demo uses fictional data in a temporary workspace. Do not use it to store personal information.

Technical details

Keyword search uses BM25. Semantic search uses a pretrained multilingual Sentence Transformers model over overlapping text passages. Hybrid search combines both rankings using reciprocal rank fusion, with metadata filters applied before ranking.

Requirement matching uses concept names, aliases, and contextual rules for supported English and German wording.
